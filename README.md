# Cafe Ordering and Billing System in C
A menu-driven console application developed in C to manage cafe orders, calculate item-wise costs, and generate a final bill.

## Overview
The Cafe Ordering and Billing System is a console-based application developed for Chile's Cafe. It provides an interactive menu that allows customers to select food and beverage items, specify quantities, view category-wise order summaries, and generate a consolidated bill before exiting.

The project demonstrates the practical application of C programming concepts, including loops, switch-case statements, variables, arithmetic operations, and formatted output.
