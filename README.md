# Cafe Ordering and Billing System in C
A menu-driven console application developed in C to manage cafe orders, calculate item-wise costs, and generate a final bill.

## Overview
The Cafe Ordering and Billing System is a console-based application developed for Chile's Cafe. It provides an interactive menu that allows customers to select food and beverage items, specify quantities, view category-wise order summaries, and generate a consolidated bill before exiting.

The project demonstrates the practical application of C programming concepts, including loops, switch-case statements, variables, arithmetic operations, and formatted output.

## Features
1. Interactive Cafe Menu: Navigate through snacks, main food, desserts, and beverages.
2. Category-Wise Ordering: Select items from individual menus.
3. Quantity Selection: Specify the quantity required for each item.
4. Automatic Bill Calculation: Calculate item totals based on quantity and price.
5. Order Summary: Display selected items, quantities, and subtotals for each category.
6. Consolidated Final Bill: Generate a final bill containing all ordered items and the total payable amount.
7. Quantity Validation: Reject quantities that are zero or negative.
8. Menu Navigation: Return to the main menu or exit and generate the final bill.

## How It Works
1. The application displays the main cafe menu.
2. The user selects a food or beverage category.
3. The selected category menu displays available items and their prices.
4. The user selects an item and enters the required quantity.
5. The program updates the item quantities and calculates the costs.
6. The user can view the category-wise order summary and return to the main menu.
7. On selecting the exit option, the application displays the final bill and total amount.
